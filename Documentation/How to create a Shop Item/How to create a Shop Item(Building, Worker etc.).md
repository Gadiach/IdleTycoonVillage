# Налаштування Shop Item

Після створення нового Shop Item він автоматично з'явиться в магазині. Щоб він відображався та працював правильно, необхідно заповнити його поля.

|Поле|Опис|
|---|---|
|**Name**|Назва предмета, яка відображається в магазині.|
|**Description**|Короткий опис предмета.|
|**Icon**|Іконка, яка відображається в магазині.|
|**Purchase Price**|Вартість покупки.|
|**Currency**|Валюта, за яку купується предмет. Від цього поля також залежить, яка іконка валюти буде показана поруч із ціною.|
|**Level**|Мінімальний рівень, необхідний для розблокування предмета.|
|**Type**|Категорія предмета (Buildings, Workers або Decorations). Визначає, у якій вкладці магазину буде відображатися предмет.|
|**Prefab**|Префаб, який буде створено після перетягування предмета з магазину на сцену.|

---

### Відображення в магазині

У картці магазину використовуються такі поля:

- **Name** → назва предмета.
- **Description** → опис.
- **Icon** → іконка предмета.
- **Purchase Price** → ціна.
- **Currency** → іконка валюти поруч із ціною.

Поля **Level**, **Type** та **Prefab** не відображаються в інтерфейсі магазину, але визначають поведінку предмета в грі.
